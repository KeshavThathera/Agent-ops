# Software installation requests

Owner: Endpoint Team.

## Approved catalogue
Common tools (browser, PDF reader, VPN client, collaboration apps) are available in the self-service Software Center and
install without administrator rights.

## Requests outside the catalogue
Submit a request with the software name, version, business justification and licence details. Requests are reviewed for
security and licensing within two working days.

## Not permitted
Unlicensed software, browser extensions that read all site data, and remote-control tools not approved by Security.
