# Password reset policy

Owner: Identity Team.

## Rules
- Support staff never ask for, or accept, a user's current password.
- Password resets require verified identity (callback to the number on file, or manager confirmation).
- New passwords must be at least 14 characters and must not reuse the last 10 passwords.
- After a reset, the user must change the temporary password at the next sign-in.

## Self-service
Users enrolled in multi-factor authentication can reset their own password from the sign-in page using "Forgot password".
