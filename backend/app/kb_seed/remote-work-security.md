# Remote work security guidelines

Owner: Security Team.

## Network
- Always connect to the VPN before accessing internal systems from outside the office.
- Avoid public Wi-Fi without the VPN. Do not use hotel or cafe networks that require installing software.

## Device
- Lock your screen when away (Windows key + L).
- Keep the laptop updated; restart when prompted for security updates.

## Reporting
Report lost or stolen devices immediately to the service desk so the device can be locked remotely.
